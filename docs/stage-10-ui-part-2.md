# Этап 10.2 — интерфейс, доступность и прерывание записи

Дата: 9 октября 2026 года. Приложение 1.9.0 / код 11; Room 7, JSON 6.

## Реализовано

- Пользовательские сообщения форм, валидаторов, импорта и статистики перенесены в Android XML-ресурсы. `AppText` использует ресурсы приложения, без Activity; JVM-тесты читают тот же XML, не отдельную таблицу переводов. Коды полей/спортов/шкал, категории и собственные названия начальных центров остаются данными. Английская инструкция не означает английского интерфейса.
- Центр сохраняется отдельной задачей ViewModel. Saveable UUID позволяет повторить создание после восстановления процесса без дубликата; другое содержимое с занятым UUID отклоняется. Состояние ожидания восстанавливается. Архивирование хранит целевое состояние, а не повторно инвертирует уже изменённое значение.
- Отмена ожидания старым экраном не сбрасывает признак незавершённой записи. Это относится к центрам, результатам, планам, удалению и отмене; восстановленный экран присоединяется к тому же запросу. Открытый редактор центра использует последний успешно прочитанный справочник.
- В альбомной ориентации используется боковая навигация с доступными названиями. Необязательные подзаголовки скрыты; диалог занимает ширину экрана, а его поля и действия прокручиваются вместе. В портретной ориентации сохраняется обычный диалог с прокруткой тела.
- Ряды фильтров, страниц и выбора повторения переносятся. Переключатели импорта/периода связаны с подписью; селектор сообщает название поля и выбранное значение. Минимальная высота селектора — 48 dp. Календарь и состояния чтения из части 10.1 сохранены.

## Найденные и исправленные дефекты

При 480×320 dp и шрифте 2.0 нижняя навигация/подзаголовок занимали почти весь экран. Узкий стандартный диалог оставлял нулевую высоту полям; после расширения открытая клавиатура всё ещё скрывала действия. Исправление: боковая навигация и единая прокрутка альбомного диалога, включая действия, с обработкой безопасных отступов окна. Настройки окна сверены с [исходником AndroidX DialogProperties](https://android.googlesource.com/platform/frameworks/support/+/d463c995fe1c3128619cc6e8039fddef46ad890a/compose/ui/ui/src/androidMain/kotlin/androidx/compose/ui/window/AndroidDialog.android.kt).

В новом тесте скалолазания первоначально была неверная подпись кнопки: `Добавить трассу` вместо `+ Добавить трассу`. Тест исправлен; итоговый полный прогон успешен. Ошибки компиляции новых импортов и XML-констант тестового JDK устранены до окончательного прогона.

## Проверки

Конфигурация: Windows, JDK Android Studio 25.0.3, Gradle 9.8.0, compile SDK 37.1. `Medium_Phone`, Android 17 / API 37, x86_64 / 16 КБ, временный `-read-only` AVD. Авиарежим включён; Wi-Fi и мобильные данные отключены. Исходная база пользователя не предоставлена и не изменялась.

```powershell
.\gradlew.bat --offline verifyOfflinePolicy testDebugUnitTest lintDebug assembleDebug assembleRelease connectedDebugAndroidTest --console plain --warning-mode all
```

Итог: 61 JVM-тест и 121 Android-тест, без failures/errors/skips; `BUILD SUCCESSFUL`. Lint: `No issues found.` Обе сборки и итоговые офлайн-манифесты проверены. Схемы Room 2–7 не изменены. Предупреждения внешних инструментов Gradle `Configuration.setVisible` и Protobuf `sun.misc.Unsafe` остаются неблокирующими.

Регрессии включают повтор создания центра после пересоздания репозитория, отменённого ожидающего клиента реальной задачи ViewModel, сохранение busy/UUID формы, футбол/две трассы с двойным шрифтом, восстановление последнего поля альбомной формы и переходы по боковой навигации. Остальные проверки частей 1–9 и 10.1 также выполнены заново.

Ручные проверки кандидатов этой части на установленном приложении:

- портретный экран 1080×2400 / 420 dpi и шрифт 2.0;
- альбомный 720×480 / 240 dpi (480×320 dp), шрифт 2.0: прокрутка до длительности, ввод `60`, доступ к обеим кнопкам при открытой цифровой клавиатуре;
- возврат в портретную ориентацию; HOME → `am kill`, подтверждённое отсутствие PID, COLD запуск без force-stop: длительность `60` восстановлена;
- сохранение/повторное подтверждение: в статистике одна игра, 0:0, учтённое и среднее время 60 минут, 1 из 1; дубля нет;
- установленный TalkBack 17.0.0.889642762: сервис подключён, touch exploration включён; проверены видимый доступный фокус, клавиатурные переходы и действия календаря/статистики. Это не полный аудит жестов и слышимого озвучивания на физическом устройстве. Системный запрос уведомлений отклонён. Настройки доступности, размера экрана, плотности и шрифта тестового AVD восстановлены.

После последнего исправления отмены ожидания выполнен полный автоматический прогон указанного финального APK. API 26, обновления установленной сборки, сквозной SAF и измерения большой истории относятся к этапу 11. Физического устройства и фактических исторических файлов нет.
