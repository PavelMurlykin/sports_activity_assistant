# Что нового в версии 1.0.1

- В расписании появилась кнопка «Отменить тренировку» под «Записать результат по плану». Она отменяет только выбранную тренировку после подтверждения. Остальные события серии сохраняются.
- В футболе подпись «Преодолено за игру, км» заменена на «Дистанция за игру, км» на всех экранах.
