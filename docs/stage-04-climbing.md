# Этап 4: справочник скалолазания и сохранность истории

Дата: 7 октября 2026 года. Сборка: `1.3.0` / код 4, Room 4, JSON 3.

## Реализовано

- Встроенные независимые справочники: французская шкала трудности и Fontainebleau болдера. Машинный код, подпись и порядок сравнения разделены. Границы списка — диапазоны приложения, не заявления о мировых рекордах.
- Для скорости — обязательный явный выбор эталонной 15 м или иной трассы, без обязательной категории сложности. Смена дисциплины сбрасывает категорию, не выполняя конверсию шкал.
- Валидатор проверяет дисциплину, систему, канонический код, исходное обозначение, тип скорости и положительное количество попыток. Новая форма не может записать неподтверждённую историческую категорию.
- Максимумы успешно пройденных трасс разделены на трудность/французскую и болдер/Fontainebleau. Скорость и неподтверждённые категории не сравниваются. Исторические попытки учитываются в количестве и процентах, с отдельным счётчиком/предупреждением. Счётчики трасс переведены на `Long`.
- Миграция `3 → 4` сохраняет исходные строки, неизвестную дисциплину, ключи/UUID, результаты, повторы и связи. Однозначные прежние категории трудности распознаются замороженным адаптером; болдеры, скорость и неизвестные/укрупнённые категории не интерпретируются автоматически.
- JSON 3 передаёт метаданные трасс. JSON 1/2 явно адаптируется; подмена версии или отсутствие метаданных в версии 3 отклоняются. Историческая неизвестная дисциплина переносится только с явным исходным названием и статусом `legacy`. Ошибки современного ввода не превращаются в исторические данные.
- Импорт выводит число неподтверждённых исторических попыток в файле. Число включает пропущенные совпадения: предупреждение относится к содержимому файла, а не только к добавленным строкам.

Происхождение, даты документов, отсутствие единого универсального классификатора и правила применимости описаны в [справочнике](climbing-grades.md). PDF-таблицы FFME и UIAA визуально сверены. Исходные файлы не изменялись. Сеть использовалась только при разработке для чтения первичных источников; в APK справочник полностью локальный.

## Проверка

Среда: Windows PowerShell, JDK Android Studio `25.0.3`, Gradle `9.8.0`, compile SDK `37.1`; эмулятор `Medium_Phone`, Android 17/API 37.1, x86_64, 16 КБ. Эмулятор работает read-only без сохранения снимка, реальные данные пользователя не использовались.

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat --offline verifyOfflinePolicy testDebugUnitTest lintDebug assembleDebug assembleRelease connectedDebugAndroidTest --warning-mode all
```

Полный успешный прогон: 134 задачи, 43 секунды; финальный повтор после очистки импорта — 32 секунды. **26 модульных и 26 Android-тестов**, 0 ошибок/падений/пропусков. Lint: `No issues found`. Debug и неподписанный release APK собраны, обе итоговые офлайн-политики проверены. Обнаруженный при первом прогоне неправильный импорт метода `assertExists` в Compose-тесте исправлен; последующие полные прогоны успешны.

Новые проверки:

- Диапазоны обеих шкал, канонизация регистра, порядок плюсов, отсутствие сравнения исторических значений.
- Применимость шкалы к дисциплине, согласованность кода/строки, скорость с обоими вариантами трассы и без оценки; отсутствие выбранной трассы скорости вызывает исправимую ошибку формы.
- Независимые максимумы только успешных подтверждённых попыток, неподтверждённая высокая категория не повышает рекорд; два `Int.MAX_VALUE` в повторах не переполняют счётчик.
- JSON 3 round-trip метаданных и исходных строк; явные адаптеры версий 1/2; повторный импорт без дубликатов в проверенном контрольном наборе.
- Настоящее открытие Room базы версии 3 с шестью разными историческими строками, включая неизвестную дисциплину; сохранность UUID, пробелов/регистра, результатов, повторов и ссылок. Экспорт этой истории и импорт в пустую базу сохраняют исходные категории/дисциплину. UUID внутри исходной базы сохраняются миграцией, но ещё не переносятся через JSON.
- Полный путь `1 → 2 → 3 → 4` на реконструированной синтетической схеме версии 1; проверка FK и сохранение агрегированных четырёх прохождений. Это не проверка реального пользовательского файла версии 1.
- Неподходящая шкала отменяет весь импорт вместе с созданием нового центра, база остаётся без изменений.
- Compose: смена дисциплины меняет справочник; скорость не содержит категории; после выбора трассы форма восстанавливается из ошибки и сохраняет результат.

Отчёты: `app/build/reports/tests/testDebugUnitTest/`, `app/build/outputs/androidTest-results/connected/debug/`, `app/build/reports/lint-results-debug.txt`.

## Ручной запуск и ограничения

Debug APK установлен и запущен в авиарежиме (`airplane_mode_on = 1`); запуск успешен, холодный старт 5514 мс (диагностика, не норматив производительности). Вручную сохранены синтетическая тренировка с тремя дисциплинами и отдельный неуспешный болдер. После принудительного перезапуска сохранились 2 тренировки, 4 попытки, 3 успеха (75%), независимые максимумы `6a` и `6A` и отсутствие максимума скорости. Прокрутка длинной формы работает, кнопки подтверждения доступны. Скриншоты формы и статистики сохранены в игнорируемом `.local-testing/`; они не содержат пользовательской истории. Перед каждым нажатием в повторном ручном сценарии состояние интерфейса читалось заново, чтобы не принимать задержку анимации за результат ввода.

Проверенный debug APK: `app/build/outputs/apk/debug/app-debug.apk`, SHA-256 `B0F7C4FA944A6801C33D0E2763EC89945D1159610C0A70C669108DEC816BFBBF`. Финальная компиляция после очистки неиспользуемого импорта дала тот же APK.

Не проверялись: реальные многолетние файлы, физическое устройство, API 26, удалённый CI. Применимость исходных шкал к конкретным залам запрошена, но ещё не подтверждена. Иные шкалы и ручное подтверждение старой категории не реализованы. Полный обмен UUID, устранение дедупликации по содержимому и восстановление всех связей планов остаются этапу 5; редактирование результатов и календарный жизненный цикл — следующим этапам. Release не подписан ключом распространения.

Неблокирующие предупреждения внешних инструментов прежние: `Configuration.setVisible` (Gradle 11), вызов `sun.misc.Unsafe` из Protobuf тестового runner на JDK 25. Сетевые разрешения не добавлены.

Русская и английская пользовательские инструкции обновлены эквивалентно с помощью `bilingual-manual-commit`. Источники проверены с помощью `pdf` в режиме чтения. Сообщение коммита: `Этап 4: разделить шкалы скалолазания и сохранить исторические категории`.
