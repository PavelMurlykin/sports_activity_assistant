# Пользовательская инструкция

## Назначение и установка

Sports Activity Assistant — самостоятельный локальный журнал футбольных тренировок и скалолазания для Android 8.0 (API 26) и выше. Аккаунт, сервер и интернет не нужны. Приложение не отправляет данные наружу. Все операции выполняются на устройстве; автоматический системный бэкап отключён, резервные копии создаются вручную в файл.

Установите debug APK из `app/build/outputs/apk/debug/app-debug.apk`, собранный по README. При установке файла Android может попросить разрешить установку из выбранного источника. Debug-сборка предназначена для локального тестирования, не для публикации. Первичная установка создаёт локальный профиль и начальные справочники, но не создаёт демонстрационные тренировки.

Перед удалением приложения или очисткой его данных сохраните резервную копию: эти действия удаляют локальную базу. Не устанавливайте тестовые сборки поверх единственной копии важной истории без предварительного сохранения файла.

Обновление до текущей схемы базы (версия 3) сохраняет локальные ключи, тренировки, количества повторов трасс, центры, планы и связи между ними. Унаследованные внешние идентификаторы профиля удаляются; локальное имя, если оно было, сохраняется. Инициализация справочников завершается до чтения и записи данных, не перезаписывая существующие записи. При некорректных связях миграция отменяется, база не пересоздаётся автоматически.

## Запись тренировки

На экране «Расписание» нажмите кнопку добавления и выберите «Записать результат». Выберите вид спорта, дату и спортивный центр, в котором доступен этот вид спорта. В текущей форме дата вводится как `YYYY-MM-DD`.

Для футбола заполните командные забитые/пропущенные голы, личные голы и голевые передачи. Нулевые результаты допустимы. При необходимости укажите дистанцию в километрах, число игроков в команде и время игры в минутах; необязательные поля можно оставить пустыми. Дистанция допускает десятичную точку или запятую. Отрицательные значения недопустимы, число игроков и время должны быть положительными, если заполнены.

Личные голы и передачи по отдельности не могут превышать число голов команды. Футбольная запись не может содержать трассы, а запись скалолазания — футбольные показатели. Общая запись и все спортивные детали сохраняются вместе: ошибка не оставляет незавершённую тренировку. Две одинаковые тренировки одного дня можно сохранить вручную; у каждой свой устойчивый идентификатор внутри базы.

Для скалолазания добавьте нужное количество трасс. Для каждой выберите дисциплину, сложность и результат «пройдена»/«не пройдена». Сейчас для всех дисциплин используется один предварительный справочник `3`–`9C`; он пока не подтверждён как официальный и не разделяет шкалы трудности и болдера. Сохраните тренировку. Её данные появятся в календаре и статистике.

Пока нет редактирования или удаления сохранённой тренировки. Проверяйте форму до сохранения; после ошибки сохранения некоторые поля могут потребовать повторного ввода. Черновик списка трасс пока не защищён от потери при повороте экрана.

## Расписание

Переключайте месяцы и выбирайте день, чтобы увидеть сохранённые результаты и планы. Кнопка добавления также позволяет выбрать «Запланировать», указать дату, спорт и центр. Доступны разовый план и еженедельное повторение с интервалом и необязательной конечной датой.

Планы не включаются в статистику состоявшихся тренировок. Пока нельзя отменить или изменить сохранённый план и нельзя записать результат непосредственно из него: результат создаётся отдельной записью, а план может остаться видимым. Исключения повторяющихся серий ещё не реализованы.

## Статистика

Экран «Статистика» показывает общее количество тренировок и месячные группы. Откройте вид спорта, чтобы увидеть показатели и список тренировок; карточка тренировки раскрывает подробности.

Футбол: игры, победы/ничьи/поражения, суммарный счёт команд, личные голы и передачи; заполненные дистанции суммируются, длительность усредняется по заполненным значениям. Скалолазание: количество прохождений с учётом исторических повторов, успешные прохождения, процент успеха, предварительный максимум сложности и распределение по дисциплинам. Максимум сложности пока общий для всех дисциплин и не подходит для сравнения разных шкал. Фильтры периода и центра пока отсутствуют.

## Спортивные центры

На экране «Центры» добавьте центр, укажите название, необязательный город и доступные виды спорта. Существующий центр можно отредактировать. Выбор центра в форме тренировки зависит от выбранного спорта. Архивирование и удаление центров пока недоступны.

## Импорт и резервная копия

На экране «Данные» нажмите «Сохранить копию в файл», выберите локальную папку в системном диалоге Android и подтвердите сохранение. JSON версии 2 содержит виды спорта, центры и их связи, тренировки со спортивными данными, разовые планы и правила повторения. Файл не зашифрован. Приложение не загружает его на сервер; если выбрать облачный провайдер системного диалога, обработка файла будет зависеть от этого стороннего приложения. Для полностью локальной работы выбирайте хранилище устройства.

Для импорта нажмите «Выбрать файл». Поддерживаются JSON-копии и футбольные CSV в UTF-8/UTF-8 BOM или Windows-1251 с разделителем `;` или `,`. Пример CSV:

```csv
user_id;training_date;sports_complex_id;team_goals_scored;team_goals_conceded;user_goals_scored;user_assists;distance_km
1;2025-12-14;2;5;3;2;1;7,35
```

Идентификатор центра должен уже существовать в приложении. Начальные центры: `1` — «Энергия Высоты» (скалолазание), `2` — «Фабрика Футбола» (футбол), `3` — «Арена на горе» (футбол). CSV пока не переносит число игроков или длительность и не импортирует скалолазание. `user_id` — только поле старого файлового формата; данные всегда попадают в локальный профиль. Не объединяйте в одном импортируемом файле историю разных людей.

Импорт объединяет записи с текущими данными, не очищая базу. Совпадающие по содержанию тренировки пропускаются; это может объединить две реальные одинаковые тренировки. Пока нет предварительного просмотра и сопоставления неизвестных центров. JSON не сохраняет связь планового события с серией и не гарантирует полный перенос всех состояний. Сохраните исходный файл и проверьте число тренировок, детали и календарь после импорта. Сообщение об успешном импорте не заменяет проверку восстановленных данных.

Неизвестный вид спорта, смешанные спортивные детали, неизвестная дисциплина или некорректное количество попыток в импортируемой тренировке вызывают ошибку без частичной записи этого файла. Старые неподдерживаемые виды спорта, уже находящиеся в базе, не удаляются: можно просматривать общие сведения, но добавление результатов для них недоступно. JSON версии 2 пока не переносит новые устойчивые идентификаторы; ограничения дедупликации по содержимому сохраняются. Начальные числовые ID центров в примере относятся только к чистой установке, после миграции они могут отличаться.

## Известные ограничения

Безопасный обмен идентификаторами, полное восстановление, отдельные шкалы скалолазания, редактирование результатов, связь плана с результатом и расширенные фильтры находятся в плане разработки и не считаются уже доступными. Совместимость с вашей многолетней историей проверяется только после получения обезличенных примеров её формата. Никакие внешние подключения для переноса файлов не нужны.

## Сборка и проверка для разработчика

Установите JDK и Android SDK согласно README, настройте `JAVA_HOME` и локальный путь SDK. Версии библиотек закреплены в `gradle/libs.versions.toml`, Wrapper — на Gradle 9.8.0 с контрольной суммой.

```powershell
.\gradlew.bat verifyOfflinePolicy testDebugUnitTest lintDebug assembleDebug
```

Первая сборка может скачать инструменты и библиотеки. После наполнения кэша эту команду можно повторить с `--offline`; самому приложению сеть не нужна. `verifyOfflinePolicy` отклоняет сетевые разрешения в итоговых debug/release манифестах и включённый автоматический бэкап. Для `connectedDebugAndroidTest` нужен запущенный эмулятор или тестовое устройство. Release APK пока не подписан ключом распространения; для установки используйте debug APK.
