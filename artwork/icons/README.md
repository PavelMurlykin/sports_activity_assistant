# Иконки приложения

Обновлены 23 октября 2026 года изображениями пользователя. Исходные PNG перенесены без перерисовки и совпадают с предоставленными файлами побайтово.

- `icon.png`: иконка приложения со спортсменами и зелёным графиком прогресса.
- `football.png`: зелёная иконка футбольного мяча с графиком.
- `climbing.png`: оранжевая иконка скалолаза у стены с графиком.
- `sports-vortex.png` и `sports-reference.png`: исторические исходники прежнего оформления, больше не используются для сборки ресурсов.

## Android-ресурсы

Из каталога проекта выполните `./scripts/prepare-icon-resources.ps1` в PowerShell на Windows. Скрипт использует System.Drawing без сетевых зависимостей и экспортирует PNG в `app/src/main/res/drawable-nodpi`: значки спорта 256 × 256, слои иконки запуска 432 × 432.

Спортивные изображения используют весь ресурсный холст без дополнительного пустого поля: отступы уже есть в исходниках. Сохраняются композиция, пропорции и цвета. В интерфейсе применяется скругление углов. Изображения отображаются без тонировки.

Иконка запуска центрирована в области 66 dp на слое 108 dp. Фоновый цвет `#021111` соответствует тёмному фону нового изображения; граница фонового квадрата сглажена. Контрастная маска формируется относительно этого же цвета для тематических иконок Android. Внешнюю форму задаёт лаунчер.

## Размеры в интерфейсе

Сохранены прежние размеры карточек, ячеек и места текста. В настройках рисунок 44 dp занимает прежний слот 32 dp и свободные отступы вокруг него; в статистике — 56 dp в слоте 40 dp; в записях результатов, планов и истории — 32 dp в слоте 24 dp.

В календаре ширина пары «спорт + состояние» остаётся прежней: 20 dp в развёрнутом виде и 18 dp в свёрнутом. Рисунок спорта увеличен до 18/16 dp, отметка состояния накладывается в правом нижнем углу. Дата, отметка дополнительных событий и доступное описание дня сохраняются. При нехватке высоты изображение ограничивается свободным местом под датой.
